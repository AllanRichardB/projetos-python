# projetos-python
Projetos desenvolvidos durante meus estudos de programação. Atividades autorais em Python, escritas por mim a partir das aulas de estudo da linguagem. Foram meu primeiro contato com lógica de programação e análise de dados.
## Projetos

| Nº | Projeto | Conceitos praticados |
|----|---------|----------------------|
| 01 | [Simulador de apostas](01-simulador-apostas) | números aleatórios, laços, condicionais |
| 02 | [Prova de recuperação](02-prova-recuperacao) | pandas, leitura de CSV, condicionais |
| 03 | [Imunidade coletiva](03-imunidade-coletiva) | simulação, laço while |
| 04 | [Temperatura e vendas](04-temperatura-vendas) | pandas, NumPy, regressão linear e polinomial |

## Como rodar

1. Instale o Python em python.org.
2. Instale as bibliotecas: `pip install -r requirements.txt`
3. Entre na pasta do projeto e execute o arquivo, por exemplo: `python apostas.py`
